# CineMetrics-Movie-Analytics-Dashboard

CineMetrics is a Power BI project where I explored movie data and built an interactive dashboard to understand how movies perform across different genres, languages, production companies, ratings, awards, and box office.

## 📊 What the Dashboard Shows

* Overall movie and box office statistics
* Genre-wise performance and ROI
* Awards and critic reviews
* Production company comparison
* Movie distribution by language and content rating
* Budget vs. box office analysis
* Average rating trends over the years

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization

## 📌 Dashboard Pages

**Summary** – Overall KPIs and movie performance

**Detailed Page 1** – Awards, production companies, languages, and content ratings

**Detailed Page 2** – Budget, box office, critic reviews, genres, and yearly ratings
